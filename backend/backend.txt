# Guards

SupabaseAuthGuard : Reject if no/invalid token (if user not logged in)
OptionalSupabaseAuthGuard:Always allow request( if loggend in or not)


Filters run automatically when i throw an error or when NestJS throws one. The filter formats all errors in one consistent way.

The filter returns errors in this format:
{
  "statusCode": 404,
  "message": "User not found",
  "path": "/api/users/123",
  "timestamp": "2024-01-01T12:30:45.000Z"
}

Middleware runs in this order: incoming request → middleware → controller → response.
